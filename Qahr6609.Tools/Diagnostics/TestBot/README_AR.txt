testbot - عميل اختبار بدون واجهة (headless) لسيرفر Qahr6609 (كلاينت 6609)
=====================================================================

البناء:
    build.bat            (بيستخدم csc.exe بتاع .NET Framework 4، الناتج testbot.exe x86)

فحص التشفير بدون شبكة:
    testbot.exe --selftest

التشغيل (السيرفرات لازم تكون شغالة: Account 9961 و Game 5817):
    testbot.exe --user USER --pass PASS --mode MODE [--report report.txt]

مفتاح LoginKey (لازم يطابق السيرفر): --loginkey KEY، أو سطر loginkey= في testaccount.ini،
أو بيتقري لوحده من Qahr6609.Shared\HazemConfig.ini ([Security] LoginKey). مفيش مفتاح مكتوب في الكود.

الأوضاع (--mode):
    auth   : سيرفر الحساب بس (1059 -> 1952 -> 1055) وبيطبع EntityID
    dh     : + اتصال بسيرفر اللعبة وتبادل مفاتيح DH وبعدين يقفل
    probe  : + يبعت 10055 برقم DLL غلط، السيرفر يرد 10050 (force close). الشخصية مش بتتحمل - آمن
    login  : دخول كامل للعالم + تسلسل 10010 + السيناريو + تقرير. تحذير: لو نفس الحساب أونلاين
             السيرفر هيفصل الجلسة التانية (Account Disconnected) - اقفل الكلاينت الأول.

خيارات تانية:
    --server MeGa          اسم السيرفر في AuthConfig.ini
    --game-host 127.0.0.1  بدل الـ IP اللي في رد 1055
    --wait 2000            مدة انتظار الرد على كل باكت (ms)
    --npc UID / --no-npc   NPC اللي يتعمله click (الافتراضي: أول NPC ظهر في 2030)
    --scenario file.txt    سيناريو مخصص، سطر لكل باكت:  الاسم | hex بعد أول 4 بايت | رقم الباكت
                           مثال:  ArenaInfo | 0 | 2209

ملاحظات:
  - محاولة دخول واحدة لكل تشغيل (LoginGuard بيقفل بعد 3 أخطاء). متكررش لو الباسورد غلط.
  - التقرير بيتكتب في report.txt جنب الـ exe: الباكتات اللي السيرفر بعتها (العدد والحجم) ورد كل باكت في السيناريو.
  - مفيش أي تعديل على Source أو AccountServer أو الداتابيز من الأداة دي، غير اللي السيرفر نفسه بيعمله عند الدخول
    (سيرفر الحساب بيكتب الـ MAC اللي في 1952 في accounts.EarthID - الأداة بتبعت "TESTBOT"، غيّره بـ --mac).

الحساب الافتراضي:
    لو مفيش --user/--pass البوت بيقرا testaccount.ini جنب الـ exe (user=... و pass=...). الباسورد مش بيتطبع أبداً.
    --account path.ini     ملف حساب تاني

إنشاء شخصية (--create):
    لو السيرفر رد بـ NEW_ROLE (الحساب مالوش شخصية) البوت بيبعت 1001 (اسم TestBot + 3 أرقام، Trojan، body 1003)
    وبعد ANSWER_OK بيبعت 10055 تاني على نفس الاتصال ويكمل الدخول للعالم. من غير --create البوت بيقف ويقول كده.
    --name NAME   --class INDEX (2 = Trojan، 0 = Taoist ... زي MsgNewRole)   --body 1003|1004|2001|2002

--mode sweep:
    دخول كامل وبعدين حوالي 100 استعلام قراءة بس (رانكات، أرينا، إليت بي كي، جيلد/كلان/يونيون، نوبيليتي، كويستات،
    تشي/جيانغهو/إنر باور، إيفنتس، بروتوباف ...). مفيش شراء/تبرع/فتح/تسجيل/claim/مسح/تليبورت.
    التقرير فيه: ANSWERED / ONLY BACKGROUND PUSHES / NO REPLY + جرد كامل للباكتات اللي السيرفر بعتها.
    مثال:  testbot.exe --mode sweep --wait 1500 --report report_sweep.txt
