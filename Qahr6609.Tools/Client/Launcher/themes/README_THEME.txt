==============================================================
 دليل تعديل شكل لانشر scripthazem
==============================================================

كل شكل اللانشر موجود في الفولدر:   themes\default\
  theme.ini     ← الإعدادات (ألوان، نصوص، صور، أماكن، مؤثرات)
  images\       ← الصور
  fonts\        ← الخطوط

● التعديل بيظهر على طول وانت فاتح اللانشر — عدّل واحفظ بس.
● تقدر تعمل أكتر من ثيم: انسخ فولدر default باسم جديد (مثلاً ramadan)
  وغيّر في launcher.ini السطر:   Theme=ramadan
● لو حطيت فولدر الثيم جوه PatchServer\www\files\themes\  هيتنزّل
  لكل اللاعبين تلقائياً مع التحديثات.

--------------------------------------------------------------
 [Window]   مقاس الشباك
--------------------------------------------------------------
 Width / Height        العرض والطول بالبكسل (الافتراضي 1120 × 720)

--------------------------------------------------------------
 [Texts]    كل الكلام اللي بيظهر
--------------------------------------------------------------
 LogoText              اسم السيرفر لو مفيش صورة لوجو
 Subtitle              السطر الصغير تحت اللوجو
 Play / PlaySub        كلام زرار اللعب (الكبير والصغير)
 Downloading / TotalProgress   عناوين شريط التحميل
 StatusOnline / StatusOffline / StatusUnknown   حالة السيرفر
 Footer                السطر الصغير تحت الشمال

--------------------------------------------------------------
 [Images]   الصور (المسار بالنسبة لفولدر الثيم، وسيبه فاضي عشان تخفيه)
--------------------------------------------------------------
 Background    الخلفية (يفضّل 1920×1200 أو أكبر، jpg)
 Character     الشخصية اللي على اليمين (png بخلفية شفافة)
 Logo          اللوجو (png شفاف) — لو فاضي هيكتب LogoText
 LogoPlate     الخامة اللي ورا اللوجو
 FrameTexture  الشريط المزخرف فوق وتحت الإطار
 PanelTexture  خامة خفيفة جوه مربع الأخبار (اختياري)
 Avatar        الصورة الصغيرة جنب عنوان الخبر

--------------------------------------------------------------
 [Background]  ضبط الخلفية (الأرقام من 0 لـ 1)
--------------------------------------------------------------
 Opacity        ظهور صورة الخلفية
 TintColor / TintOpacity   لون فوق الخلفية وقوته (يدّي جو عام)
 LeftShade      تغميق الجزء الشمال عشان الكلام يبان
 BottomShade    تغميق الجزء اللي تحت
 PatternOpacity النقشة المعينات الخفيفة
 ---- سلايدشو الخلفية (صور بتتبدّل ورا الكارت، رخيصة على المعالج) ----
 Slideshow=1/0    تشغيل/إقفال السلايدشو (0 = خلفية ثابتة زي الأول)
 Folder           فولدر الصور (كل jpg/png جواه)، الافتراضي backgrounds
 Images           صور بعينها بفاصلة (بتتجاهل Folder)، مثال: Images=backgrounds/a.jpg,backgrounds/b.jpg
 IntervalSeconds  كام ثانية كل صورة (الافتراضي 10)
 FadeMs           مدة التحول بالملي ثانية (الافتراضي 1500)
 Order            sequential (بالترتيب) أو random (عشوائي)
 KenBurns=0       سيبه 0 (زووم بطيء = استهلاك معالج)
 Video            فيديو خلفية اختياري (فاضي = مقفول). ثقيل؛ بيشتغل بس لو الكارت قوي (Tier>=2)
 * الصور بتتحمّل بحجم العرض وبتتخزّن (cache)، والتحول بيحصل مرة كل IntervalSeconds بس،
   وبيقف تماماً لما الشباك يتصغّر أو مش مُفعّل — صفر معالج بين التحولات.

--------------------------------------------------------------
 [Music]   موسيقى الخلفية (loop) + زرار الكتم فوق
--------------------------------------------------------------
 Enabled=1/0      تشغيل/إقفال الموسيقى
 File             ملف الصوت بالنسبة للثيم (wav مضمون؛ mp3/ogg محتاج كودك)
 Volume           الصوت الافتراضي 0..100 (المستخدم يغيّره من الإعدادات)
 StartMuted=1/0   يبدأ مكتوم؟
 PauseWhenMinimized=1/0  يوقف الصوت لما يتصغّر؟ (الافتراضي 0)
 * اختيار المستخدم للصوت/الكتم بيتحفظ في launcher.ini [Music] ويفضل بعد ما يقفل ويفتح.

--------------------------------------------------------------
 [Character]   الشخصية
--------------------------------------------------------------
 Show=1/0       إظهار/إخفاء
 Height         الطول بالبكسل (ممكن أطول من الإطار عشان تطلع برّه)
 Right / Bottom المسافة من يمين وتحت
 Flip=1         يقلب الصورة (تبص للناحية التانية)
 GlowColor / GlowSize / GlowOpacity   الإضاءة اللي حواليها

--------------------------------------------------------------
 [Colors]   الألوان بصيغة #AARRGGBB
--------------------------------------------------------------
 AA = الشفافية (FF = مش شفاف ، 80 = نص شفاف ، 00 = مخفي)
 GoldLight / Gold / GoldDark   درجات الدهبي (الإطارات واللوجو والأزرار)
 Accent        لون التاج [UPDATE] واسم الملف
 Author        لون اسم الكاتب
 Text / DimText   لون الكلام العادي والباهت
 Panel         خلفية مربع الأخبار
 FileBar / TotalBar   لون شريطين التحميل
 PlayText      لون كلام زرار اللعب

--------------------------------------------------------------
 [Fonts]
--------------------------------------------------------------
 Title   خط العناوين وزرار اللعب:  fonts/الملف.ttf#اسم الخط
 Body    خط الكلام العادي (اسم خط متسطب زي Segoe UI أو Tahoma)

--------------------------------------------------------------
 [Layout]
--------------------------------------------------------------
 NewsWidth      عرض مربع الأخبار
 ShowGallery    إظهار الصور التلاتة تحت الخبر
 ShowStatus     إظهار حالة السيرفر
 PanelTextureOpacity   قوة خامة مربع الأخبار

--------------------------------------------------------------
 [Effects]
--------------------------------------------------------------
 Embers=1/0     الشرار اللي بيطلع لفوق
 EmberCount     عدده
 EmberColor     لونه

--------------------------------------------------------------
 [Gallery] و [OfflineNews]
--------------------------------------------------------------
 الصور والخبر اللي بيظهروا لو سيرفر الأخبار مقفول.
 الأخبار الحقيقية بتتعدل من:  PatchServer\www\news.json
   {"items":[{"tag","title","date","author","body","link"}],
    "images":[{"url":"news/1.jpg","caption":"...","link":""}]}

--------------------------------------------------------------
 تنبيه عن الصور
--------------------------------------------------------------
 الصور الحالية مرخّصة للاستخدام التجاري مجاناً (شوف CREDITS.txt).
 لو هتحط صور جديدة استخدم صور بتاعتك أو بترخيص يسمح، ومتستخدمش
 رسومات ألعاب تانية أو شخصيات ليها حقوق.


=== ثيم ليالي رمضان (RAMADAN NIGHTS) ===
فيه ثيم موسمي جاهز في فولدر themes\ramadan (سما بالليل وهلال وفوانيس وقافلة).
التفعيل: افتح launcher.ini اللي جنب اللانشر وخلّي السطر  Theme=ramadan
الرجوع:   Theme=default
الثيم ده بياخد اللوجو والشخصية والخط من فولدر default، فأي تعديل هناك هيظهر في الاتنين.
تقدر تغيّر الشخصية مثلاً:  Character=../default/images/char_hero.png
التحديثات والأخبار والزرار "ابدأ اللعب" شغالين زي ما هما مع أي ثيم.


==============================================================
 لانشر v2 (2026-10-12) - المفاتيح الجديدة
==============================================================
 التصميم ثابت على مقاس 1060×625 وبيصغر لوحده لو الشاشة صغيرة ([Window] Width/Height مبقتش مستخدمة)

 [Images]  Frame = خلفية الإطار الغامق (png بظل)   Card = ورقة الأخبار الفاتحة (png بحواف مقطوعة)
 [Logo]    Image = صورة اللوجو فوق الإطار (فاضي = لوجو HAZEM المرسوم)   Width / OffsetY
           Ribbon / Ribbon_en = الكلام في الشريط الذهبي تحت اللوجو (فاضي = يختفي)   DiscColor = لون الدايرة/الشريط
 [Character] Height + Right + Bottom = المسافة من يمين وتحت الشباك كله (الشخصية بتطلع برة الإطار)
 [Card]    Title / Text / Dim / Tag / Link / Author = ألوان الكلام على الورقة ، TintColor + TintOpacity = تلوين الورقة
 [Colors]  Ornament = لون الخطوط الذهبية الرفيعة
 [Texts]   StatusOnline / StatusOffline / StatusMaintenance (+ _en) = كلام حالة السيرفر تحت زرار اللعب
 [Fonts]   Body = fonts/Cairo-Regular.ttf#Cairo ، Logo = fonts/Cinzel-Bold.ttf#Cinzel
 [Effects] Embers=0 افتراضي: الجزيئات بتخلي الشباك الشفاف يترسم كل فريم (حوالي 12% من نواة) - شغّلها بس لو عايزها (أقصى 15)

 الأخبار (news.json): body بيقبل **كلام عريض** و [نص الرابط](https://...)
 launcher.ini: GamePort= (اختياري) بيتفحص مع LoginPort لحالة السيرفر ، DirectX=8 أو 9 (من الإعدادات)
